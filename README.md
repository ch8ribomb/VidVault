# BlogPix v3.1

網頁貼文圖片批次下載工具（視窗版）。在瀏覽器裡用滑鼠點選或框選，一次存下整篇貼文的所有圖片，**不需要找網址**。
微博為精準解析；其他網站為盡力解析（取滑鼠所在區塊內的圖片）。

## 使用
1. 執行 `BlogPix_v3.1.exe`（不需安裝），保持視窗開著。
2. 瀏覽器安裝 Tampermonkey，新增指令碼並貼上 `BlogPix.user.js` 的內容（只需一次）。
3. 到網頁上下載圖片，有兩種方式：
   - **點按鈕**：滑鼠移到貼文的圖片上，點出現的橘色「⬇ BlogPix」按鈕，下載整篇。
   - **框選＋快捷鍵**：用滑鼠框選想下載的區塊（框到圖片就只下載選到的圖；只框到文字則下載該篇全部），再按快捷鍵（預設 `Ctrl+Alt+D`）。
   - 滑鼠停在貼文上直接按快捷鍵也可以。
4. 備用：「下載」分頁最下方可直接貼上網址下載。

快捷鍵可在「快捷鍵與進階」分頁變更，會檢查是否與 Windows、其他程式或常見瀏覽器快捷鍵衝突；也可停用快捷鍵，或關閉網頁上的按鈕。

## 設定（「儲存位置與檔名」分頁）
**儲存位置**：每次下載前詢問／固定使用預設資料夾／沿用上次位置

**檔名**
1. 使用網路上的原始檔名（已存在時可選擇略過或另存為 `名稱 (1)`）
2. 批量重新命名（命名格式可用 `{post}` 貼文代碼、`{n}` 序號、`{orig}` 原檔名、`{date}` 日期，可設定起始編號與位數）
3. 批量重新命名，並檢查目的資料夾是否已存在該批圖片（已存在的圖不重複下載；資料夾內會有隱藏的 `.blogpix_index.json` 記錄來源圖片與存檔名）

**檔案格式**：沿用原始格式／轉換為 JPG、PNG、WEBP、BMP、TIFF、GIF（畫面會列出最近一篇貼文的原始格式）。
動態圖（GIF／WebP 動畫）不轉檔，保留原格式；轉成 JPG／BMP 時透明背景會填白。

設定檔位於 `%APPDATA%\BlogPix\config.json`。

## 自行執行原始碼
    pip install -r requirements.txt
    python blogpix.py

## 自行打包
    pip install pyinstaller
    pyinstaller --onefile --windowed --name BlogPix_v3.1 --icon BlogPix.ico --add-data "BlogPix.ico;." blogpix.py

## 安全性說明
瀏覽器腳本與程式透過本機 `127.0.0.1` 通訊，只接受帶有專用標頭的請求，且會拒絕指向本機或內網位址的圖片網址。
微博 Cookie（選填）等同登入憑證，只存在本機設定檔，請勿分享。

## 版本紀錄
- **v3.1**：網頁圖片上浮出「⬇ BlogPix」按鈕，點一下下載整篇；支援滑鼠框選區塊（框到圖片只下載選到的）；網址欄改為備用。
- **v3.0**：改為視窗介面；儲存位置三種模式；檔名三種模式（含檢查已存在）；可選擇轉換格式；
  快捷鍵可自訂並檢查衝突，可停用；支援手動貼網址；不再限定微博（其他網站盡力解析）。
- **v2.0**：改名 BlogPix；沿用原始檔名；待命模式（滑鼠指著貼文按 D）；加入程式圖示；版本號納入檔名。
- **v1.0**：`weibo_dl`，貼上微博貼文網址批次下載。

> 發佈新版時：修改 `blogpix.py` 內的 `__version__`，打包出的 exe 檔名會自動帶入版本號。
